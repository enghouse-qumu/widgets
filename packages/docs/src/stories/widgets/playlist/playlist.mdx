# Playlist widget

The playlist widget plays several presentations one after the other, in a persistent player.

It shows the player, a control bar and the list of the presentations. Clicking a row plays its presentation; when a presentation ends, the next one starts. The widget remembers what the viewer watched, so they can continue where they left off.

## Basic Usage

By default, the widget shows the thumbnail of the first presentation, the control bar and a row per presentation, with its title and duration. Here, the first 6 presentations of a saved Smart Search.

## Recipes

### Hide the player

`showPlayer: false` hides the video and keeps the control bar and the list, for audio-style playlists like podcasts. The player is still loaded and plays the sound. With a `height`, the list takes the remaining height and scrolls.

<Canvas of={Stories.HiddenPlayer}/>

### Choose the row fields

The rows have 2 slots: `left`, which takes the remaining width, and `right`, aligned at the end. They take the same fields as the [list widget](?path=/docs/widgets-list--docs#fields), including metadata fields. The rows show one line per field; `lineClamp` allows more.

<Canvas of={Stories.RowFields}/>

### Style the widget

Every part can be styled: the player, the control bar and its menus, the list, the rows and their current and watched states, and each field separately. Here, an indigo control bar, rounded rows and a fixed height: the list scrolls.

<Canvas of={Stories.Styling}/>

### Follow the playback

`onItemChange` is called when the current item changes, and `onPlaylistEnd` when the last item ends. Play the first item and let the playlist run.

<Canvas of={Stories.Events}/>

### Control the playlist from your page

The widget instance has methods to change the current item, and gives access to the [Player SDK](https://qumu.github.io/player-sdk/) of the current item's player, e.g. to seek or listen to its events.

<Canvas of={Stories.InstanceApi}/>

<Tip title="The Player SDK changes with the item">Each item is played in a new player: `playerSdk` returns the SDK of the current one. It is `undefined` before the first item is loaded.</Tip>


## Behavior

- **First item:** `playbackMode` defines how the first item starts: its thumbnail (`inline`), its player paused (`inline-autoload`), or playing (`inline-autoplay`). The following items always play automatically.
- **Selection:** clicking a row plays its presentation. Clicking the current row plays or pauses it. The current row is highlighted, and scrolled into view inside the list; the page itself never scrolls.
- **Auto-advance:** when an item ends, the next one plays. With `trackProgress`, the next unwatched item is preferred. After the last item, the playlist stops and calls `onPlaylistEnd`, or continues with the first item with `loop`.
- **Previous and next:** the buttons go to the adjacent items, watched or not. They are disabled at the ends of the playlist, unless `loop` is set.
- **Progress:** with `trackProgress`, the progress of each presentation is saved in the browser (`localStorage`, key `qumu-widget-progress`). The playlist starts from the first unwatched item, a partially watched item resumes where the viewer left it and shows its watched time (`00:08 / 00:20`), and watched items show a replay icon. Without storage, e.g. in a private window, the progress is not tracked.
- **Viewer choices:** the captions, audio track, volume, quality and playback speed chosen by the viewer are kept for the following items.
- **Controls:** the widget renders its own control bar, the same for every presentation: `playerParameters.showControlPanel` is ignored. The settings menu works like the one of the player: it lists the playback speed and the quality, each one opening its own submenu. The optional buttons and settings are hidden when the current item has nothing to offer, e.g. the captions button without captions, or the audio languages button with a single audio track. On touch devices, the volume slider is replaced by the mute button only.
- **Live events:** a live event shows a Live badge instead of the seek bar, and the audience reactions while it runs. Auto-advance skips the live events which have already ended.
- **Hidden player:** with `showPlayer: false`, the captions, quality and fullscreen buttons are hidden, and the player uses the lowest quality, `240p`, unless `playerParameters.quality` is set.
- **Loops:** `playerParameters.loop` loops the current item and disables the auto-advance; it takes precedence over `loop`.
- **Keyboard:** every control is a native button or slider. The seek bar moves by 5 seconds with the arrow keys and by 10% with Page Up and Page Down; the menus are navigated with the arrow keys and closed with Escape; in the settings menu, Right arrow opens a setting and Left arrow returns to the settings, like in the player. The focus ring of a row is drawn around the whole row.
- **Screen readers:** the widget is a region named "Playlist", the control bar a group named "Player controls". Each row's button is named after the presentation title and described by the other fields and its state (now playing, watched or in progress). The new item is announced after an auto-advance or previous/next.
- **Formatting:** the dates and the durations are formatted for the language of the page, see [Localization](?path=/docs/getting-started-localization--docs).
- **No results:** the widget shows a "No presentations found" message when the source returns no presentations, or when they cannot be fetched.


## API

### PlaylistWidget

| Property/Method                                                                           | Type                                         | Description                                                                                                                                                  |
|-------------------------------------------------------------------------------------------|----------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------|
| version                                                                                   | `string`                                     | The widget's version.                                                                                                                                        |
| currentIndex                                                                              | `number`                                     | The index of the current item, `-1` when the playlist is empty.                                                                                              |
| presentations                                                                             | `Presentation[]`                             | The presentations of the playlist.                                                                                                                           |
| playerSdk                                                                                 | `PlayerSdk \| undefined`                     | The [Player SDK](https://qumu.github.io/player-sdk/) of the current item's player. It changes with the item, and is `undefined` before the player is loaded. |
| static create(configuration: [PlaylistWidgetConfiguration](#playlistwidgetconfiguration)) | `Promise<PlaylistWidget>`                    | Create the widget.                                                                                                                                           |
| select(indexOrGuid: number \| string, play = true)                                        | `void`                                       | Select an item, by its index or the GUID of its presentation, and play it unless `play` is `false`.                                                          |
| next()                                                                                    | `void`                                       | Play the next item.                                                                                                                                          |
| previous()                                                                                | `void`                                       | Play the previous item.                                                                                                                                      |
| destroy()                                                                                 | `void`                                       | Destroy the widget and clean up the DOM.                                                                                                                     |

### PlaylistControls

The play/pause, previous and next buttons, the seek bar and the times are always shown. An optional button is also hidden when the current item has nothing to offer.

| Property          | Type      | Default | Description                                                                                            |
|-------------------|-----------|---------|--------------------------------------------------------------------------------------------------------|
| volume            | `boolean` | `true`  | Defines whether the mute button and the volume slider are shown. The slider is not shown on touch devices. |
| audioTracks       | `boolean` | `true`  | Defines whether the audio languages menu is shown, when the item has several audio tracks.            |
| captions          | `boolean` | `true`  | Defines whether the captions menu is shown, when the item has captions. Not shown when `showPlayer` is `false`. |
| playbackRate      | `boolean` | `true`  | Defines whether the playback speed is shown in the settings menu.                                      |
| quality           | `boolean` | `true`  | Defines whether the quality is shown in the settings menu. Not shown when `showPlayer` is `false`.     |
| audienceReactions | `boolean` | `true`  | Defines whether the audience reactions menu is shown, for the running live events.                     |
| fullscreen        | `boolean` | `true`  | Defines whether the fullscreen button is shown, for the player and the control bar. Not shown when `showPlayer` is `false`. |

#### Control Bar

The control bar takes four colors, like the player, and derives the others from them with the player's formulas:

- the menus have the general background color at 90% opacity,
- the hover and pressed states of the buttons and the menu options have the general color at 13% and 20% opacity,
- the track of the sliders has the general color at 30% opacity,
- the slider thumb and the volume level are 7.5% darker on hover and 15% darker while dragged, the menu separators 75% darker,
  or lighter (and 55% lighter for the separators) when the general color is dark,
- the keyboard focus rings have the primary background color, 2px away from the element.

The thumb of the seek bar shows only on hover and keyboard focus, like the player. In fullscreen, the control bar has more room from
the edges of the screen.

| Property                           | Default    | Description                                                                                          |
|------------------------------------|------------|------------------------------------------------------------------------------------------------------|
| controls.general.backgroundColor   | `#09091a`  | The background color of the control bar and of the menus.                                            |
| controls.general.color             | `#f5f8fa`  | The color of the times, the buttons, the menus and the sliders.                                      |
| controls.primary.backgroundColor   | `#00b0ff`  | The background color of the current option of the menus, the color of the keyboard focus rings and of the played part of the seek bar. |
| controls.primary.color             | `#013b55`  | The text color of the current option of the menus.                                                   |
| controls.fontFamily                | inherited  | The font family of the control bar.                                                                  |

#### Fields

Each field is styled separately, keyed by its `field`, with the same properties as the [list widget's fields](?path=/docs/widgets-list--docs#fields-1). In the rows, the fields default to `14px`, the title in a `500` weight, and show a single line unless `lineClamp` is set.

```js
style: {
  item: {
    metadata: {
      title: { fontWeight: '600' },
      duration: { color: '#6b7280', fontSize: '12px' },
    },
  },
},
```
