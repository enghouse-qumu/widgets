# List widget

The list widget shows several presentations, in a **grid** or a **vertical** list.

Each item shows the thumbnail of a presentation and information fields around it, like its title, publication date, publisher or any metadata. Clicking an item plays the presentation in a modal.

## Basic Usage

By default, the widget uses the `grid` layout and shows the title and the publication date of each presentation.

### Vertical layout

The `vertical` layout shows one presentation per row, with the information next to the thumbnail.

### Use a Smart Search

The presentations can come from a list of GUIDs, a saved Smart Search, or Smart Search rules defined in the configuration. Here, the presentations whose title contains "driverless", sorted by title.

### Choose the information fields

The fields are placed in 4 slots around the thumbnail: `top`, `left`, `right` and `bottom`. Each field shows its default label, except the title and the summary; property `label` hides it (`false`), shows it (`true`) or replaces it (a string).

### Limit the number of columns

With a number, `columns` is the maximum number of columns: the grid shows fewer columns when the items would get narrower than `minItemWidth`. Resize the window to see the columns adapt.

<Canvas of={Stories.Columns}/>

### Style the items

Every part of the items can be styled: the item itself and its hover state, the thumbnail, the play button, the duration badge, and each information field separately. Here, white tiles with the thumbnail at the top, a small eyebrow above a big title, a short summary taken from a metadata field, and a custom play icon: an inline SVG given to `playIconUrl`.

And a newspaper look for the `vertical` layout: a red accent, serif headlines and summaries, plain rows divided by a vivid bottom line, with a square play icon and the duration badge in the bottom corners of the thumbnail.

`onItemClick` replaces the modal, e.g. to open the presentation in a page of your own application.

## Behavior

- **Playback:** clicking anywhere on an item opens the presentation in a modal, or calls `onItemClick` when it is set.
- **Text selection:** the text of the items can be selected and copied. A click ending a text selection does not open the presentation.
- **Links:** the links of a Markdown metadata field open in a new tab, they do not open the presentation.
- **Keyboard:** the thumbnail is the play button of the item. Its focus ring is drawn around the whole item, which also takes its hover style.
- **Screen readers:** the play button is named after the presentation title and described by the other fields. The fields are description lists, so each value is announced with its label, even when the label is hidden.
- **Formatting:** the dates and the durations are formatted for the language of the page, see [Localization](?path=/docs/getting-started-localization--docs).
- **No results:** the widget shows a "No presentations found" message when the source returns no presentations, or when they cannot be fetched.

### ListWidgetSource

The source must define **exactly one** of `smartSearchGuid`, `presentationGuids` or `smartSearch`.

| Property          | Type                            | Required | Default                                                            | Description                                                                                                                                                                       |
|-------------------|---------------------------------|----------|--------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| host              | `string`                        | **Yes**  | `''`                                                               | Defines the Qumu Cloud tenant to get the presentations from (i.e: demo.qumucloud.com).                                                                                            |
| smartSearchGuid   | `string`                        | One of   | `undefined`                                                        | Defines the GUID of a saved Smart Search.                                                                                                                                         |
| presentationGuids | `string[]`                      | One of   | `undefined`                                                        | Defines the GUIDs of the presentations to show, in this order.                                                                                                                    |
| smartSearch       | [SearchFilter](#searchfilter)   | One of   | `undefined`                                                        | Defines Smart Search rules.                                                                                                                                                       |
| limit             | `number`                        | No       | `12` (`grid`), `10` (`vertical`), the number of `presentationGuids` | Defines the maximum number of presentations to show.                                                                                                                              |
| offset            | `number`                        | No       | `0`                                                                | Defines the number of presentations to skip.                                                                                                                                      |
| sortBy            | `string`                        | No       | `'created'`                                                        | <p>Defines the property to sort the presentations by, e.g. `published` or `title`.</p><p>⚠️ Only with `smartSearchGuid` or `smartSearch`.</p> |
| sortOrder         | `string`   | No       | `'DESCENDING'`                                                     | <p>Defines the order to sort the presentations. Value must be one of: `ASCENDING`, `DESCENDING`.</p><p>⚠️ Only with `smartSearchGuid` or `smartSearch`.</p>                                                                       |


### SearchFilter

| Property | Type                          | Description                                                                 |
|----------|-------------------------------|-----------------------------------------------------------------------------|
| match    | `string`                      | Defines whether the presentations must match all the rules, or any of them. Value must be one of: `all`, `any`. |
| rules    | [SearchRule[]](#searchrule)   | Defines the rules.                                                          |

### SearchRule

| Property   | Type     | Description                                                                                                                                                                                                                                                                                |
|------------|----------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| field      | `string` | Defines the field to search: a presentation property, e.g. `title` or `published`, or the GUID of a metadata field.                                                                                                                                                                        |
| comparator | `string` | Defines how to compare the field with the value. Value must be one of: `is`, `is_not`, `contains`, `does_not_contain`, `contains_any`, `less_than`, `greater_than`, `greater_than_or_equal_to`, `less_than_or_equal_to`, `between`, `not_between`, `in_the_last`, `not_in_the_last`, `in_the_next`, `not_in_the_next`. |
| value      | `string` | <p>Defines the value to compare the field with.</p><p>The relative date comparators (`in_the_last`, `in_the_next`…) take an offset and a unit, e.g. `30,DAYS`, `6,MONTHS` or `1,YEARS`.</p>                                                                                                |


### ListWidgetOptions

| Property     | Type                                                       | Default                       | Description                                                                                                                                                             |
|--------------|------------------------------------------------------------|-------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| layout       | `string`                                                   | `'grid'`                      | <p>Defines the layout.</p><ul><li>`grid`: several presentations per row.</li><li>`vertical`: one presentation per row, the information next to the thumbnail.</li></ul> |
| item         | [Partial&lt;ItemTemplateConfig&gt;](#itemtemplateconfig)   | See [Layouts](#layouts)       | Defines the content of the items.                                                                                                                                       |
| playIconUrl  | `string`                                                   | `undefined`                   | Defines the URL to a custom play icon image.                                                                                                                            |

### ItemTemplateConfig

| Property            | Type                                                                         | Default                 | Description                                                                                                                       |
|---------------------|------------------------------------------------------------------------------|-------------------------|-----------------------------------------------------------------------------------------------------------------------------------|

| info                | `Partial<Record<'top' \| 'left' \| 'right' \| 'bottom', InfoFieldConfig[]>>` | See [Layouts](#layouts) | <p>Defines the fields to show in each slot around the thumbnail, in order.</p><p>When set, it replaces the default fields entirely.</p> |

### InfoFieldConfig

| Property | Type                | Default                                       | Description                                                                                                                       |
|----------|---------------------|-----------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------|
| field    | `string`            |                                               | Defines the field, see [Fields](#fields).                                                                                         |
| label    | `string \| boolean` | Hidden for `title` and `summary`, shown otherwise | <ul><li>`true`: show the default label.</li><li>`false`: hide the label.</li><li>a string: show this label.</li></ul> |

### Fields

| Field            | Value                                         | Default label                     |
|------------------|-----------------------------------------------|-----------------------------------|
| `title`          | The title of the presentation.                | Title (hidden)                    |
| `summary`        | The summary of the presentation.              | Summary (hidden)                  |
| `publisher`      | The name of the publisher.                    | Published by                      |
| `publishOn`      | The publication date, e.g. September 24, 2026. | Published on                      |
| `duration`       | The duration, e.g. 01:05.                     | Duration                          |
| a metadata GUID  | The value of the metadata field.              | The name of the metadata field    |

The fields without a value are not shown. Metadata values are formatted according to their type: dates, numbers, the options of select fields, and Yes or No for booleans. Markdown values are rendered, with their links opening in a new tab.

### Layouts

The layout changes the default values; each one can still be overridden.

| Layout     | `source.limit` | `item.info`                                                            |
|------------|----------------|------------------------------------------------------------------------|
| `grid`     | `12`           | `{ bottom: [{ field: 'title' }, { field: 'publishOn' }] }`             |
| `vertical` | `10`           | `{ right: [{ field: 'title' }, { field: 'summary' }, { field: 'publisher' }] }` |

#### Fields

Each field is styled separately, keyed by its `field`: `item.metadata.title`, `item.metadata.publishOn`, or `item.metadata['<metadata GUID>']`.

```js
style: {
  item: {
    metadata: {
      title: { fontWeight: '700', lineClamp: 2 },
      publishOn: { fontSize: '12px', labelColor: '#777' },
      myMetadataGUID: { labelColor: '#999' };
    },
  },
},
```

| Property                          | Default                                     | Description                                                                                                      |
|-----------------------------------|---------------------------------------------|------------------------------------------------------------------------------------------------------------------|
| item.metadata[field].color        | inherited                                   | The text color of the field.                                                                                     |
| item.metadata[field].hoverColor   | `color`                                     | The text color of the field when the item is hovered.                                                            |
| item.metadata[field].labelColor   | the text color, at 70% opacity              | The color of the label.                                                                                          |
| item.metadata[field].hoverLabelColor | `labelColor`                             | The color of the label when the item is hovered.                                                                 |
| item.metadata[field].fontFamily   | inherited                                   | The font family of the field.                                                                                    |
| item.metadata[field].fontSize     | `16px` (`title`), `14px` (the others)       | The font size of the field.                                                                                      |
| item.metadata[field].fontWeight   | `600` (`title`), `400` (the others)         | The font weight of the field.                                                                                    |
| item.metadata[field].letterSpacing | inherited                                  | The letter spacing of the field.                                                                                 |
| item.metadata[field].textTransform | inherited                                  | The text transform of the field, e.g. `uppercase`.                                                               |
| item.metadata[field].lineClamp    | `undefined`                                 | The maximum number of lines of the field; the rest is truncated with an ellipsis.                                |
| item.metadata[field].padding      | `0`                                         | The spacing around the field.                                                                                    |
