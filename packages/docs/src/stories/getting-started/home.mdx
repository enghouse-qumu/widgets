# Qumu Widgets

This is the documentation for the Qumu Widgets.

We currently offer the current widgets;

* Presentation widget: A widget displaying a single presentation that can be played inlined or in a modal (this replaces the old Playback and Thumbnail widgets).
* List widget: A widget showing a list of presentations in a grid or vertical list layout (this replaces the old Grid and Vertical widgets).
