# Icons

The icons of the player controls come from the Qumu UI kit, like the legacy widgets, and are copied unchanged:
the UI kit is published on a private registry, which the build of this public package cannot use.

| Icon                                                                                                                                                  | Source in `@enghouse-qumu/ui-kit@8.0.1` |
|-------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------|
| `cc`, `chevron-left`, `expand`, `hd`, `mute`, `pause`, `play`, `playback-rate`, `restart`, `settings`, `shrink`, `skip`, `smiley`, `volume-max` | `icons/qumu/<name>.svg`                 |
| `user-sound`                                                                                                                                          | `icons/phosphor/regular/user-sound.svg` |

To update them, copy the files of a newer version of the UI kit and update its version above.
